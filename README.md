# UtilSNR

A comprehensive toolkit for Unity developed by **Sonaru**, designed to streamline development with common patterns and utility functions.

## Installation

### Via Git URL
Open the Unity Package Manager (`Window > Package Manager`), click the `+` icon, select `Add package from git URL...`, and paste:
```
https://github.com/SonaruIsuge/UtilSNR.git
```
